Real Python, two ways

Online, code runs in a Python interpreter inside your browser. On localhost, the same page sends it to your own CPython through POST /api/run, with a 5-second safety timeout.

Run it on your computer

Your own localhost, your own Python.

The local kit is one folder with index.html and server.py. It needs nothing but Python 3.8 or newer.

  1. 1

    Unzip the PyForge kit

    Put the pyforge folder anywhere, for example on your Desktop.

  2. 2

    Start the server

    Open Terminal in that folder and run python3 server.py (Windows: py server.py).

  3. 3

    Open it in Safari

    Go to http://localhost:8000. The runtime badge switches to CPython · localhost.
